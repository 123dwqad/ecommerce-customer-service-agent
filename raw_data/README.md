## 重新生成

脚本：`scripts/generate_commerce_docs.py`（依赖 reportlab，本机可用 RAG 项目 venv）：

```powershell
python -m scripts.generate_commerce_docs
```

店铺名称、文档编号等常量在脚本顶部，修改后重新运行即可整体更新。

## 接入 RAG 索引

修改或新增文档后，重建索引（按 mtime 增量）：

```powershell
.\.venv\Scripts\python.exe -m scripts.build_commerce_rag
```

索引未就绪时 `rag_search` 会后台自动构建，当前请求回退关键词检索。入库与检索架构见 `docs/commerce_rag.md`。
